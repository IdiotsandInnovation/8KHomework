# 8KHomework
Works on LWSD school computers with Python installed from software center. Unsure on other districts' computers.

- I am not responsible for any trouble you get in for using this program
- Your mileage WILL vary, as these are pretty untested scripts and I am just generally terrible at coding in Python.
- Please run this script in another desktop, terminal/shell windows are quite sus to your teachers and peers.

## Files:
- ib.py: disables iBoss, but you will need to also change your DNS to something like 1.0.0.1/1.1.1.1 (Cloudflare), or 8.8.8.8 (Google), or your preferred DNS resolver. This program is NOT mine
- dk.py: disables DyKnow (deprecated)
- scly.py: disables Securly, the monitoring program used by teachers. I made this program because I was bored in my CS P class, but I'm not sure how well it works.
- java.py: installs Java 25 JDK into the C: directory of your computer. I used this to get the latest version on Java MC running.
